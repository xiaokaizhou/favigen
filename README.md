# 🔥 Favigen — Free Favicon Generator

Generate favicons in every size (16, 32, 48, 64, 96, 128, 180, 192, 256, 512), a multi-resolution **ICO**, and an **Apple Touch** icon — in one click.

**100% client-side.** Your image never leaves the browser. No server, no upload, no tracking. Free forever.

## ✨ Features
- 📐 All standard sizes + high-DPI (up to 512px)
- 🟦 Single `.ico` with embedded 16/32/48/64/128/256 layers
- 🍎 `apple-touch-icon.png` (180px) for iOS home-screen
- 🎨 Optional rounded corners + padding
- 📦 One-click `.zip` of every PNG
- 🔒 Privacy-first: everything runs in your browser via Canvas
